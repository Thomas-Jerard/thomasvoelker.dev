# thomasvoelker.dev — project doctrine

This file outranks casual chat. It travels with the GitHub repo so a wiped
sandbox can be restored instead of redesigned.

## Log-off save (non-negotiable)

When the user says they are **calling it a night**, **logging off**, **stopping
for the day**, or any equivalent:

1. Commit all project work (source, public assets, this file).
2. Push to `origin` on GitHub: `Thomas-Jerard/thomasvoelker.dev`.
3. Reply with the repo URL and that the save landed.
4. Do **not** leave the only copy in the Grok sandbox.

Do this automatically. Do not ask. Do not wait.

If GitHub is disconnected, say so in one line and stop — do not pretend it saved.

## Restore before you invent

On a fresh sandbox: clone `Thomas-Jerard/thomasvoelker.dev` and continue from
that tree. Do **not** rebuild from memory. Last night’s files were lost once
because a session started empty and the work was reconstructed. That does not
happen again.
